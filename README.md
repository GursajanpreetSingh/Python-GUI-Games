# 🖥️ Python GUI Games

A collection of Python GUI games built using Turtle and other GUI programming concepts.

## 🎮 Games

| Game                     | Description                                                                                              | Concepts                                                         |
| ------------------------ | -------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 🐍 [Snake](./Snake-Game) | A classic Snake game with food, scoring, high-score tracking, collision detection, and keyboard controls | Turtle, OOP, Keyboard Events, Collision Detection, File Handling |

## 🛠️ Concepts Practiced

* Python GUI programming
* Turtle graphics
* Object-Oriented Programming
* Keyboard event handling
* Game loops and animation
* Collision detection
* File handling
* Score and high-score management
* Modular code organization

## 🎯 Purpose

This repository contains GUI-based Python games created as hands-on practice projects. Each game focuses on applying Python programming concepts to build interactive applications while improving problem-solving and programming skills.
